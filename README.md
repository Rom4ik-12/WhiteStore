# WhiteStore 🛍️

**WhiteStore** — лёгкий, быстрый и современный сторонний клиент каталога приложений **RuStore** для Android, созданный в строгом соответствии с гайдлайнами **Google Material Expressive (Material 3)**.

В приложении нет рекламы, сторисов, всплывающих баннеров, трекеров и навязчивых аккаунтов. Только чистый каталог, поиск и удобная установка приложений.

---

## ✨ Ключевые возможности

- 🎨 **Google Material Expressive Design (Material 3):**
  - Поддержка динамических цветов **Material You (Android 12+)**, подстраивающихся под обои вашего рабочего стола.
  - Полноценная тёмная и светлая темы с возможностью переключения в настройках (`Система` | `Светлая` | `Тёмная`).
  - **Adaptive & Themed Icon**: адаптивная иконка и поддержка монохромных тематических значков Android 13+.
- 🔍 **Поиск и подсказки прямо под строкой ввода:**
  - Быстрый поиск по каталогу с автоматическим debounce и корректным percent-encoding запросов.
  - Подсказки с миниатюрами и иконками всплывают аккуратным выпадающим списком.
- 📦 **Минималистичные карточки и информативная карточка приложения:**
  - В общем каталоге карточки приложений компактные и чистые, без огромных отвлекающих кнопок.
  - Внутри приложения: галерея скриншотов, раздел «Что нового», статистика скачиваний, рейтинг, категория, размер APK и полное описание.
- 📥 **Умная загрузка и распаковка:**
  - Наглядные статусы кнопки действия: `Подготовка...` ➔ `Скачивание: X% (МБ)` ➔ `Распаковка...` ➔ `Установить`.
  - Автоматическая распаковка универсальных `.apk` из `.zip`-контейнеров RuStore для крупных приложений (например, СберБанк Онлайн).
  - Безопасная передача APK в системный инсталлятор пакетов через `FileProvider`.
- 🔄 **Вкладка «Моё» и живые обновления:**
  - Плитка **«Мои приложения»** с точным количеством установленных пользовательских программ и быстрым запуском.
  - Плитка **«Обновления»** с автоматической проверкой актуальных версий в RuStore, показом иконок доступных обновлений, красным бейджем и кнопкой **«Обновить всё»**.
  - Карточка проверки обновлений самого клиента **WhiteStore**.
- 🔒 **Изолированная работа с сертификатами Минцифры и HARICA:**
  - Сертификаты НУЦ Минцифры и HARICA подключены исключительно для доменов RuStore через `OkHttpClient` и `network_security_config.xml`.
  - Системное хранилище доверенных сертификатов Android не подменяется и изолировано от стороннего трафика.

## 🛠 Технологический стек

| Компонент | Технология |
|---|---|
| **Язык** | Kotlin 2.0.21 |
| **UI Framework** | Jetpack Compose (Material 3 Expressive, Compose BOM 2025.04.01) |
| **Архитектура** | MVVM + StateFlow + Coroutines |
| **Сетевой стек** | OkHttp 4.12.0 + kotlinx.serialization 1.7.3 |
| **Загрузка изображений** | Coil 3.1.0 (с OkHttp fetcher) |
| **Навигация** | Jetpack Navigation Compose 2.8.9 |
| **Целевой SDK** | Android 15 (API 35), минимальный SDK: Android 8.0 (API 26) |

## 🚀 Сборка и установка

### Сборка через Gradle

```bash
# Клонируйте проект и перейдите в корень:
cd WhiteStore

# Сборка Debug APK:
./gradlew assembleDebug
```

Готовый файл APK будет находиться по пути:
```
app/build/outputs/apk/debug/app-debug.apk
```

### Установка на устройство через ADB

Убедитесь, что отладка по USB включена на вашем устройстве, и выполните:
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
