Автономный, легковесный и открытый клиент каталога приложений RuStore для Android. Построен на современных технологиях Jetpack Compose и Material 3 Expressive без навязчивых сервисов, рекламы, трекеров и обязательной авторизации.

---

## Архитектура и стек технологий

- **Язык разработки**: Kotlin 2.0.21
- **UI Toolkit**: Jetpack Compose + Material 3 Expressive (Compose BOM 2025.04.01)
- **Архитектурный паттерн**: MVVM (Model-View-ViewModel) + Single Activity + StateFlow
- **Сетевой клиент**: OkHttp 4.12.0 c поддержкой изолированных SSL-сертификатов (Минцифры / HARICA)
- **Сериализация**: kotlinx.serialization 1.7.3 (JSON)
- **Асинхронность**: Kotlin Coroutines + Flow
- **Кеширование и оптимизация**: 
  - `AppIconLoader` с собственным LRU-кешем битмапов в памяти для мгновенной отрисовки сотен установленных пакетов без пауз сборщика мусора (GC)
  - Coil 3.1.0 с OkHttp-движком для сетевой графики и скриншотов
- **Фоновые задачи**: AlarmManager + BroadcastReceiver с проверкой типа сетевого подключения

## Используемые API-эндпоинты

Приложение взаимодействует с публичными API-шлюзами RuStore без необходимости ввода приватных ключей или учетных записей:

| Метод | Эндпоинт | Назначение |
|---|---|---|
| `GET` | `https://backapi.rustore.ru/applicationData/v2/search` | Поиск приложений по названию и ключевым словам с пагинацией |
| `POST` | `https://backapi.rustore.ru/applicationData/autocomplete` | Получение поисковых подсказок при вводе запроса |
| `GET` | `https://backapi.rustore.ru/applicationData/overallInfo/{packageName}` | Детальная информация: метаданные, скриншоты, версия, рейтинг и число отзывов |
| `GET` | `https://backapi.rustore.ru/applicationData/v2/download-link` | Получение прямой ссылки на загрузку универсального APK или ZIP-пакета |
| `GET` | `https://api.github.com/repos/Rom4ik-12/WhiteStore/releases/latest` | Автопроверка и доставка обновлений клиента WhiteStore |

## Функциональные возможности

### Каталог и поиск
- Поиск с автоматической задержкой ввода (debounce) и корректным URL-кодированием.
- Быстрые подсказки с миниатюрами и иконками прямо под поисковой строкой.
- Просмотр детальных сведений: скриншоты в полноэкранном режиме, описание, список изменений («Что нового»), рейтинг, распределение оценок и категория.

### Установка и менеджмент обновлений
- Автоматическая распаковка универсальных `.apk` из архивов `.zip` для крупных приложений.
- Прямая передача пакетов системному установщику через защищенный `FileProvider`.
- Выбор сетевого профиля для обновлений: «Любая сеть» или «Только Wi-Fi» для экономии мобильного трафика.
- Ручная и настраиваемая автоматическая проверка обновлений в фоне (выкл, 6 ч, 12 ч, 24 ч) с опциональными пуш-уведомлениями.
- Список исключений («Игнорируемые приложения») для блокировки обновлений выбранных пакетов.
- Моментальная реакция на системные события установки: статус и счетчик обновлений сбрасываются сразу после завершения инсталляции.

### Персонализация и дизайн (Material 3 Expressive)
- Отдельное подменю «Дизайн»:
  - Тема оформления: Системная, Светлая или Тёмная.
  - Динамическая палитра Material You (Android 12+) из обоев рабочего стола.
  - Ручной выбор из 6 акцентных цветов при отключенном Monet.
  - Настройка формата кнопок в списке обновлений: полноразмерная кнопка либо компактная кнопка-иконка.
  - Настройка формата версий: только целевая (`v2.0 • 45 МБ`) либо наглядный переход (`1.0 ➔ 2.0`).
  - Переключатель отображения красного бейджа со счетчиком обновлений на главной плитке.

### Оптимизация производительности
- Раздельное чтение метаданных приложений и отложенное асинхронное декодирование иконок на базе LRU-кеша `AppIconLoader`.
- Устойчивый 60/120 FPS-скролл списков установленных приложений на устройствах с более чем 100+ установленными программами.

## Безопасность и сертификаты

Для корректной работы с российскими сервисами без риска для операционной системы:
- Сертификаты Национального удостоверяющего центра Минцифры РФ и HARICA встроены локально в ресурсы приложения.
- Сертификаты активируются строго для сетевых запросов к доменам `*.rustore.ru` через кастомный `SSLSocketFactory` и `network_security_config.xml`.
- Системное хранилище корневых сертификатов Android не модифицируется, посторонний сетевой трафик устройства не перехватывается.

## Сборка из исходников

### Требования
- JDK 17 (OpenJDK 17 или выше)
- Android SDK (API 35, Build-tools 35.0.0+)

### Инструкция по сборке

```bash
# Клонирование репозитория
git clone https://github.com/Rom4ik-12/WhiteStore.git
cd WhiteStore

# Сборка Debug APK
./gradlew assembleDebug

# Сборка оптимизированного Release APK
./gradlew assembleRelease
```

Собранные APK-пакеты формируются в директории:
- `app/build/outputs/apk/debug/app-debug.apk`
- `app/build/outputs/apk/release/app-release.apk`
